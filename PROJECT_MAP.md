- `backend/src/main/java/com/library/` — REST controllers, entities, repositories, security
- `backend/src/main/resources/db/migration/` — Flyway schema + seed data
- `frontend/` — browser UI consuming REST API
- `database/` — database notes/manual SQL location
- `docs/` — architecture and API documentation
